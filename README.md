# 🐱 Projeto: Curiosidades sobre Gatos 🐾

Olá! Bem-vindo(a) ao repositório do meu projeto web sobre o fantástico mundo dos felinos! Este site foi desenvolvido com muito carinho para partilhar factos surpreendentes sobre os nossos amigos de quatro patas. ✨

---

## 🚀 Funcionalidades & Destaques do Projeto

* **🖼️ Cabeçalho Personalizado:** Imagem de fundo (`capa.jpeg`) com efeito de transparência moderna para destacar a apresentação.
* **✨ Título Animado:** Efeito visual dinâmico (*pulse/glow*) no título principal que flutua no topo da página.
* **📦 Cards de Conteúdo Organizadinhos:** Cada curiosidade está num bloco exclusivo com:
  * 🏷️ Nome do site de origem no topo.
  * 📸 Imagens temáticas (`imagem1`, `imagem2`, `imagem3`).
  * 🔗 **Links Dinâmicos:** Podes clicar tanto na imagem como no link de texto para navegar até à fonte!
  * 📝 Informações detalhadas sobre a genética, história e expectativa de vida dos gatos.
* **📱 Design Responsivo:** Adapta-se perfeitamente ao ecrã do computador, tablet ou telemóvel.

---

## 📚 Curiosidades Incluídas

1. 🌍 **A Origem:** O ancestral selvagem *Felis silvestris lybica*.
2. 🐯 **95,6% Tigre:** O incrível genoma partilhado com o maior felino do mundo.
3. ⏳ **Expectativa de Vida:** Como os anos dos gatos se comparam aos 100 anos humanos!
